# Museum Seat Scout

Build a small, clean web application called MuseumPass for browsing museums and booking visit slots. Include:

A list of museums with exhibition/category tags, time slots, ticket price, and remaining available seats.

Search and category filter controls.

A booking form/modal where a user selects a museum, date/time slot, visitor name (demo/placeholder), and ticket quantity (1–10). Validate inputs and prevent booking more tickets than available seats.

A "My Bookings" view showing created bookings with a button to cancel a booking and restore available seats.

Seed data with 4–5 museums and clear state management, plus a basic test setup if possible. Do not include real authentication secrets or external paid API keys.
